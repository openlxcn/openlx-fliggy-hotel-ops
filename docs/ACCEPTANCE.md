# 分项验证

运行记录以随版本的 `references/status.json` 与 evidence 文件为准。

已执行的本地行为验证：价格类型、销售主体、价格计划及条件隔离；全量更新拒绝；变动上限、冷却与陈旧数据；套餐预约、已履约及部分退款；净结算费用不重复扣减；信用住有效房晚；五星含投诉不自动回复；报告脱敏与付费去推广署名；导入不能冒充LIVE；模拟支付金额、幂等与续期；设备令牌与租约；中央通票签名、时效、账号、产品和物业隔离。

浏览器检查：首页12项优势、月季年价格切换、桌面与手机无横向溢出、会员登录表单、关闭购买状态、报告演示标识与页面脚本错误。

安装检查会使用实际ZIP解压安装并运行doctor、导入和报告。检查有效只证明包可运行，不证明真实平台字段适配。
