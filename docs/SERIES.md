# 与携程、美团同步协作

系列共享身份为wx.openlx.cn；各产品保留平台适配、登录Profile、产品ID和独立版本。二维码、账号验证、SMTP和支付模块共用已有实现。

当前协作目录在同级`coordination`。携程任务负责wx系列数据服务与MySQL新增表，飞猪只修改本产品接入；不同时改动共享schema。已实现通过持久化outbox把本产品酒店、订单、权益、设备元信息与工单状态送入中央系列视图，并按相同用户读取聚合概览。

中央数据同步不等于自动授予跨产品权限，也不代替通票签发。全局物业ID和各平台酒店绑定需核实，不能仅按同名酒店或自填字符串合并。

如共享服务不可用，保留待同步记录和原始顺序，免费本地体检、报告继续。只有中央接口明确回执与回读后，才能报告系列数据库同步完成。

完整传输协议与字段见 [SERIES-CONTRACT.md](SERIES-CONTRACT.md)。当前产品代码已接入；真实中央注册、ack和回读以evidence/series-production.json为准。

生产已注册飞猪独立同步流，中央stream_id与本地一致，revision/ack均0，待发0；当前无实际飞猪业务记录，不能称为已完成真实订单迁移。通票签发没有因为同步上线而自动完成。
