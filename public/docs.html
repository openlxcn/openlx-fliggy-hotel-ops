GET STARTED WITH OPENLX

从一份完整体检开始。

本版已提供可安装技能、离线经营分析与账号适配执行工具。真实飞猪商家后台需核对你的酒店、销售主体和当前页面后接入。

安装与首次使用

  1. 在首页下载技能包，对照SHA-256后解压。
  2. 准备Node.js 22.20及以上。进入技能目录，执行安装命令。
  3. 建立酒店独立工作区，按随包示例整理经营导出。
  4. 导入并生成报告。没有后台适配时也可完成这条免费流程。
node scripts/install.mjs install
node scripts/ops.mjs doctor
node scripts/ops.mjs init --workspace /path/to/hotel-work --hotel hotel-id --name 酒店名称
node scripts/ops.mjs import --workspace /path/to/hotel-work --file /path/to/snapshot.json
node scripts/ops.mjs report --workspace /path/to/hotel-work

安装脚本默认使用 ~/.codex/skills/openlx-fliggy-hotel-ops；也可通过 --target 指定目标。数据工作区放在技能目录之外，升级时保留。

如何接入飞猪后台

技能使用独立Chrome配置，不读取日常浏览器默认Profile。登录和验证码由你完成；执行前核对酒店名称地址、账号、销售主体、价格计划和字段。现有网页执行器需要真实页面映射，不能凭平台名称猜测选择器。

普通动作可以使用一次明确的范围授权。好评自动回复先开通范围授权；差评、混合评价和事实不明情况确认具体文案。写入后核对同一个对象，超时先回读，不重复盲发。

价格与套餐口径

SUPPLY代表供货价，RETAIL代表客人零售价，不能直接互换。酒店净结算不再重复扣掉已含佣金、商家优惠和平台费。套餐份额、有效权益、已预约和已履约分别记录。

信用住按实际有效订单与履约状态统计，不以未预付直接判无效。只有飞猪渠道数据时，全店入住率、ADR和RevPAR保持未知。搜索位置需要记录查询条件，广告位与自然结果分开。
